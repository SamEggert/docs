title: "Custom domain"

---

Para configurar tu documentación en un domain personalizado, deberás establecer el domain personalizado deseado en la configuración de Mintlify y ajustar la configuración de DNS en tu proveedor de domain.

<Info>
  ¿Quieres configurar un subdirectorio personalizado como `mintlify.com/docs`? Consulta la documentación de [subdirectorio personalizado](/es/deploy/cloudflare).
</Info>

<div id="dashboard-settings">
  ## Configuración del dashboard
</div>

1. Ve a tu [dashboard](https://dashboard.mintlify.com)
2. Selecciona **Settings**
3. Selecciona **Domain Setup**
4. Ingresa el domain personalizado que quieras. Por ejemplo, `docs.mintlify.com`

<div id="configuring-your-dns">
  ## Configuración de tu DNS
</div>

1. Ve a la configuración de DNS de tu domain en el sitio web de tu proveedor de domain.
2. Crea una nueva entrada de DNS e introduce los siguientes valores:

```bash
CNAME | docs | cname.vercel-dns.com.
```

<div id="provider-specific-settings">
  ## Configuraciones específicas del proveedor
</div>

<AccordionGroup>
  <Accordion title="Vercel verification">
    Si Vercel es tu proveedor de domain, debes añadir un registro `TXT` de verificación. Esta Información aparecerá en tu dashboard después de enviar tu domain personalizado y también te llegará por correo electrónico.
  </Accordion>

  <Accordion title="Cloudflare security settings">
    Si Cloudflare es tu proveedor de DNS, debes habilitar la opción de seguridad &quot;full strict&quot; para la configuración de HTTPS.
  </Accordion>
</AccordionGroup>
