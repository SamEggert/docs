title: "PostHog"
---

Agrega lo siguiente a tu archivo `docs.json` para enviar Analíticas a PostHog.

Solo necesitas incluir `apiHost` si haces self-hosting de PostHog. De forma predeterminada enviamos los eventos a `https://app.posthog.com`.

<CodeGroup>

```json Opciones de Analytics en docs.json
"integrations": {
    "posthog": {
        "apiKey": "YOUR_POSTHOG_PROJECT_API_KEY",
        "apiHost": "optional"
    }
}
```

```json Ejemplo
"integrations": {
    "posthog": {
        "apiKey": "phc_TXdpocbYTeZVm5VJmMzHTMrCofBQu3e0kN7HGMNGTVW"
    }
}
```

</CodeGroup>

<br />

<Warning>
    Habilitar las Analíticas de PostHog deshabilitará las Analíticas en el Panel de control de Mintlify.
</Warning>

<div id="session-recordings">
  ## Grabaciones de sesiones
</div>

Debes agregar la URL de tu sitio de documentación a la opción “Authorized domains for recordings” de Posthog antes de poder recibir grabaciones de sesiones. La opción para agregar tu URL se encuentra en la configuración del proyecto de Posthog.
