<div id="add-an-asyncapi-specification-file">
  ## Agregar un archivo de especificación de AsyncAPI
</div>

Para empezar a crear páginas para tus websockets, asegúrate de contar con un documento de esquema de AsyncAPI válido en formato JSON o YAML que cumpla con la [especificación de AsyncAPI](https://www.asyncapi.com/docs/reference/specification/v3.0.0). Tu esquema debe ajustarse a la especificación AsyncAPI 3.0 o superior.

<Tip>
  Para verificar que tu esquema de AsyncAPI sea válido, puedes pegarlo en
  [AsyncAPI Studio](https://studio.asyncapi.com/)
</Tip>

<div id="auto-populate-websockets-pages">
  ## Autogenerar páginas de websockets
</div>

Puedes agregar un campo `asyncapi` a cualquier pestaña o grupo en la Navegación de tu `docs.json`. Este campo puede contener la ruta a un documento de esquema AsyncAPI en tu repositorio de documentación, la URL de un documento de esquema AsyncAPI hospedado o un arreglo de enlaces a documentos de esquema AsyncAPI. Mintlify generará automáticamente una página por cada canal de websocket de AsyncAPI.

**Ejemplos con Tabs:**

<CodeGroup>
  ```json Local File {5}
  "navigation": {
    "tabs": [
      {
          "tab": "API Reference",
          "asyncapi": "/path/to/asyncapi.json"
      }
    ]
  }

  ```

  ```json Remote URL {5}
  "navigation": {
    "tabs": [
      {
          "tab": "API Reference",
          "asyncapi": "https://github.com/asyncapi/spec/blob/master/examples/simple-asyncapi.yml"
      }
    ]
  }
  ```
</CodeGroup>

**Ejemplos con Groups:**

```json {8-11}
"navigation": {
  "tabs": [
    {
      "tab": "AsyncAPI",
      "groups": [
        {
          "group": "Websockets",
          "asyncapi": {
            "fuente": "/path/to/asyncapi.json",
            "directory": "api-reference"
          }
        }
      ]
    }
  ]
}
```

<Note>
  El campo directory es opcional. Si no se especifica, los archivos se colocarán en
  la carpeta **api-reference** del repositorio de docs.
</Note>


<div id="channel-page">
  ## Página de canal
</div>

Si quieres tener más control sobre el orden de tus canales o simplemente hacer referencia a un solo canal, puedes crear un archivo MDX con el campo `asyncapi` en el frontmatter.

```mdx
---
title: "Canal WebSocket"
asyncapi: "/path/to/asyncapi.json channelName"
---
```
