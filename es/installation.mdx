<div id="installing-the-cli">
  ## Instalación de la CLI
</div>

<Info>
  **Requisito previo**: Instala [Node.js](https://nodejs.org/en) antes de continuar.
</Info>

<Steps>
  <Step title="Instalar la CLI.">
    Ejecuta el siguiente comando para instalar la [CLI](https://www.npmjs.com/package/mint):

    <CodeGroup>
      ```bash npm
      npm i -g mint
      ```

      ```bash pnpm
      pnpm add -g mint
      ```
    </CodeGroup>
  </Step>

  <Step title="Vista previa local.">
    Ve al directorio de tu documentación (donde se encuentra el archivo `docs.json`) y ejecuta el siguiente comando:

    ```bash
    mint dev
    ```

    La vista previa local de tu documentación estará disponible en `http://localhost:3000`.
  </Step>
</Steps>

Como alternativa, si no quieres instalar la CLI globalmente, puedes ejecutar un script de una sola vez:

```bash
npx mint dev
```

<div id="updates">
  ## Actualizaciones
</div>

Si la vista previa local no coincide con lo que ves en la versión de producción en la web, actualiza tu CLI local:

```bash
mint update
```

Si el comando `mint update` no está disponible en tu versión local, reinstala la CLI con la versión más reciente:

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

<div id="custom-ports">
  ## Puertos personalizados
</div>

De forma predeterminada, la CLI utiliza el puerto 3000. Puedes personalizarlo con la opción `--port`. Para ejecutar la CLI en el puerto 3333, por ejemplo, usa este comando:

```bash
mint dev --port 3333
```

Si intentas ejecutar en un puerto que ya está en uso, se usará el siguiente puerto disponible:

```mdx
El puerto 3000 ya está en uso. Probando con el 3001.
```

<div id="previewing-as-a-specific-group">
  ## Vista previa como un grupo específico
</div>

Si usas autenticación parcial para restringir el acceso a tu documentación, puedes obtener una vista previa como un grupo de autenticación específico usando la opción `--group [groupname]`.

Por ejemplo, si tienes un grupo llamado `admin`, puedes obtener una vista previa como miembro de ese grupo con el siguiente comando:

```bash
mint dev --group admin
```

<div id="additional-commands">
  ## Comandos adicionales
</div>

<div id="find-broken-links">
  ### Encontrar enlaces rotos
</div>

Identifica los enlaces internos rotos con el siguiente comando:

```bash
mint broken-links
```

<div id="find-accessibility-issues">
  ### Detectar problemas de accesibilidad
</div>

Prueba las relaciones de contraste de color y busca texto alternativo faltante en imágenes y videos de tu documentación con el siguiente comando:

```bash
mint a11y
```

<div id="check-openapi-spec">
  ### Comprobar la especificación de OpenAPI
</div>

Comprueba tu archivo de OpenAPI en busca de errores con el siguiente comando:

```bash
mint openapi-check <nombre de archivo OpenAPI o URL>
```

Pasa un nombre de archivo (por ejemplo, `./openapi.yaml`) o una URL (por ejemplo, `https://petstore3.swagger.io/api/v3/openapi.json`).

<div id="rename-files">
  ### Renombrar archivos
</div>

Renombra y actualiza todas las referencias a los archivos con el siguiente comando:

```bash
mint rename <ruta/al/nombre-archivo-anterior> <ruta/al/nombre-archivo-nuevo>
```

<div id="migrate-mdx-endpoint-pages">
  ### Migrar páginas de puntos de conexión en MDX
</div>

Migra páginas de puntos de conexión en MDX a páginas autogeneradas a partir de tu especificación de OpenAPI con el siguiente comando:

```bash
mint migrate-mdx
```

Este comando convierte las páginas individuales de puntos de conexión en MDX en páginas autogeneradas definidas en tu `docs.json`, mueve el contenido de MDX a la extensión `x-mint` en tu especificación de OpenAPI y actualiza tu navegación. Consulta [Migrating from MDX](/es/guides/migrating-from-mdx) para obtener información detallada.

<div id="formatting">
  ## Formato
</div>

Durante el desarrollo local, recomendamos usar extensiones en tu IDE para reconocer y formatear archivos `MDX`.

Si usas Cursor, Windsurf o VS Code, recomendamos la [extensión MDX para VS Code](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) para el resaltado de sintaxis y [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) para el formateo de código.

Si usas JetBrains, recomendamos el [plugin MDX para IntelliJ IDEA](https://plugins.jetbrains.com/plugin/14944-mdx) para el resaltado de sintaxis y configurar [Prettier](https://prettier.io/docs/webstorm) para el formateo de código.

<div id="troubleshooting">
  ## Solución de problemas
</div>

<AccordionGroup>
  <Accordion title="Error: No se pudo cargar el módulo &#x22;sharp&#x22; usando el runtime darwin-arm64">
    Esto puede deberse a una versión desactualizada de Node. Prueba lo siguiente:

    1. Desinstala la versión actual de la Mint CLI: `npm uninstall -g mint`
    2. Actualiza a Node.js.
    3. Vuelve a instalar la Mint CLI: `npm install -g mint`
  </Accordion>

  <Accordion title="Problema: Aparece un error desconocido">
    **Solución**: Ve al directorio raíz de tu dispositivo y elimina la carpeta `~/.mintlify`. Después, ejecuta `mint dev` de nuevo.
  </Accordion>

  <Accordion title="Error: permiso denegado">
    Esto se debe a no tener los permisos necesarios para instalar paquetes de Node globalmente.

    **Solución**: Intenta ejecutar `sudo npm i -g mint`. Se te pedirá tu contraseña, que es la que usas para desbloquear tu computadora.
  </Accordion>

  <Accordion title="La vista previa local no se ve igual que mis docs en la web">
    Es probable que se deba a una versión desactualizada de la CLI.

    **Solución:** Ejecuta `mint update` para obtener los cambios más recientes.
  </Accordion>

  <Accordion title="mintlify vs. paquete mint">
    Si tienes algún problema con el paquete de la CLI, primero ejecuta `npm ls -g`. Este comando muestra qué paquetes están instalados globalmente en tu máquina.

    Si no usas npm o no lo ves en la lista con -g, prueba `which mint` para localizar la instalación.

    Si tienes un paquete llamado `mint` y otro llamado `mintlify` instalados, deberías desinstalar `mintlify`.

    1. Desinstala el paquete antiguo:

    ```bash
      npm uninstall -g mintlify
    ```

    2. Limpia la caché de npm:

    ```bash
      npm cache clean --force
    ```

    3. Vuelve a instalar el paquete nuevo:

    ```bash
    npm i -g mint
    ```
  </Accordion>
</AccordionGroup>
