Claude Code es una herramienta de línea de comandos con capacidades de agente que puede ayudarte a mantener tu documentación. Puede redactar nuevo contenido, revisar páginas existentes y mantener la documentación actualizada.

Puedes entrenar a Claude Code para que comprenda tus estándares y flujos de trabajo de documentación añadiendo un archivo `CLAUDE.md` a tu proyecto y afinándolo con el tiempo.

<div id="getting-started">
  ## Introducción
</div>

**Requisitos previos:**

* Suscripción activa a Claude (Pro, Max o acceso a la API)

**Configuración:**

1. Instala Claude Code:

```bash
  npm install -g @anthropic-ai/claude-code
```

2. Ve a tu directorio de docs.
3. (Opcional) Añade el archivo `CLAUDE.md` a tu proyecto.
4. Ejecuta `claude` para empezar.


<div id="claudemd-template">
  ## Plantilla de CLAUDE.md
</div>

Guarda un archivo `CLAUDE.md` en la raíz de tu directorio de documentación para ayudar a Claude Code a comprender tu proyecto. Este archivo entrena a Claude Code con tus estándares de documentación, preferencias y flujos de trabajo. Consulta [Gestionar la memoria de Claude](https://docs.anthropic.com/en/docs/claude-code/memory) en la documentación de Anthropic para obtener más información.

Copia esta plantilla de ejemplo o ajústala según las especificaciones de tu documentación:

```mdx
# Documentación de Mintlify

## Relación de trabajo
- Puedes cuestionar ideas: esto puede llevar a una mejor documentación. Cita fuentes y explica tu razonamiento cuando lo hagas
- SIEMPRE pide aclaraciones en lugar de hacer suposiciones
- NUNCA mientas, adivines o inventes nada

## Contexto del proyecto
- Formato: archivos MDX con frontmatter YAML
- Configuración: docs.json para navegación, tema, configuraciones
- Componentes: componentes de Mintlify

## Estrategia de contenido
- Documenta lo justo para el éxito del usuario: ni demasiado, ni muy poco
- Prioriza la precisión y usabilidad
- Haz el contenido duradero cuando sea posible
- Busca contenido existente antes de agregar algo nuevo. Evita la duplicación a menos que se haga por una razón estratégica
- Verifica patrones existentes para mantener consistencia
- Comienza haciendo los cambios más pequeños y razonables

## docs.json

- Consulta el [esquema de docs.json](https://mintlify.com/docs.json) al construir el archivo docs.json y la navegación del sitio

## Requisitos de frontmatter para páginas
- title: Título de página claro y descriptivo
- description: Resumen conciso para SEO/navegación

## Estándares de escritura
- Voz en segunda persona ("tú")
- Prerrequisitos al inicio del contenido procedimental
- Prueba todos los ejemplos de código antes de publicar
- Coincide con el estilo y formato de páginas existentes
- Incluye casos de uso básicos y avanzados
- Etiquetas de lenguaje en todos los bloques de código
- Texto alternativo en todas las imágenes
- Rutas relativas para enlaces internos

## Flujo de trabajo de Git
- NUNCA uses --no-verify al hacer commit
- Pregunta cómo manejar cambios sin commit antes de comenzar
- Crea un nuevo branch cuando no exista un branch claro para los cambios
- Haz commit frecuentemente durante el desarrollo
- NUNCA omitas o deshabilites los hooks de pre-commit

## No hagas
- Omitir frontmatter en ningún archivo MDX
- Usar URLs absolutas para enlaces internos
- Incluir ejemplos de código sin probar
- Hacer suposiciones: siempre pide aclaraciones
```


<div id="sample-prompts">
  ## Prompts de ejemplo
</div>

Una vez que hayas configurado Claude Code, prueba estos prompts para ver cómo puede ayudar con tareas comunes de documentación. Puedes copiar y pegar estos ejemplos directamente o adaptarlos a tus necesidades específicas.

<div id="convert-notes-to-polished-docs">
  ### Convierte notas en documentación de calidad
</div>

Convierte borradores en páginas de Markdown bien formadas con components y frontmatter.

**Ejemplo de indicación:**

```text wrap
Convierte este texto en una página MDX con el formato correcto: [pega tu texto aquí]
```


<div id="review-docs-for-consistency">
  ### Revisar la documentación para mantener la coherencia
</div>

Obtén sugerencias para mejorar el estilo, el formato y el uso de componentes.

**Ejemplo de prompt:**

```text wrap
Revisa los archivos en docs/ y sugiere mejoras para la consistencia y claridad
```


<div id="update-docs-when-features-change">
  ### Actualiza la documentación cuando cambien las funciones
</div>

Mantén la documentación actualizada a medida que tu producto evoluciona.

**Ejemplo de prompt:**

```text wrap
Nuestra API ahora requiere un parámetro de versión. Actualiza nuestra documentación para incluir version=2024-01 en todos los ejemplos
```


<div id="generate-comprehensive-code-examples">
  ### Generar ejemplos de código completos
</div>

Crea ejemplos multilenguaje con manejo de errores.

**Ejemplo de solicitud:**

```text wrap
Crea ejemplos de código para [tu endpoint de API] en JavaScript, Python y cURL con manejo de errores
```


<div id="extending-claude-code">
  ## Extender Claude Code
</div>

Además de indicarle instrucciones manualmente a Claude Code, puedes integrarlo en tus flujos de trabajo existentes.

<div id="automation-with-github-actions">
  ### Automatización con GitHub Actions
</div>

Ejecuta Claude Code automáticamente cuando cambie el código para mantener la documentación al día. Puedes activar revisiones de la documentación en pull requests o actualizar los ejemplos cuando se detecten cambios en la API.

<div id="multi-instance-workflows">
  ### Flujos de trabajo multiinstancia
</div>

Usa sesiones separadas de Claude Code para distintas tareas: una para redactar contenido nuevo y otra para la revisión y el control de calidad. Esto ayuda a mantener la coherencia y a detectar problemas que una sola sesión podría pasar por alto.

<div id="team-collaboration">
  ### Colaboración en equipo
</div>

Comparte el archivo `CLAUDE.md` perfeccionado con tu equipo para garantizar estándares de documentación coherentes entre todos los colaboradores. A menudo, los equipos desarrollan indicaciones (prompts) y flujos de trabajo específicos del proyecto que se integran en su proceso de documentación.

<div id="custom-commands">
  ### Comandos personalizados
</div>

Crea comandos con barra diagonal reutilizables en `.claude/commands/` para tareas de documentación frecuentes específicas de tu proyecto o equipo.
