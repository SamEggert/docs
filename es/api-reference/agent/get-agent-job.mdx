<div id="usage">
  ## Uso
</div>

Este endpoint obtiene los detalles y el estado de una tarea del agente específica mediante su identificador único. Úsalo para consultar el progreso, el estado y los resultados de una tarea del agente creada previamente.

<div id="job-details">
  ## Detalles del trabajo
</div>

La respuesta incluye información como:

- Estado de ejecución del trabajo y estado de finalización
- Información de la branch y detalles del pull request
- Metadatos de la sesión y marcas de tiempo
