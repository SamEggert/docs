---
openapi: GET /agent/{projectId}/jobs
---

<div id="usage">
  ## Uso
</div>

Este endpoint recupera todas las tareas del agente para el domain especificado, y ofrece una vista general de todas las actividades del agente y su estado actual. Resulta útil para supervisar y gestionar múltiples tareas del agente, tanto concurrentes como históricas.

<div id="response">
  ## Respuesta
</div>

Utiliza este endpoint para obtener una visión completa de todas las sesiones anteriores del agente.
