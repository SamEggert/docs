<Info>
  Los preview deployments están disponibles en los [planes Pro y Enterprise](https://mintlify.com/pricing?ref=preview-deployments).
</Info>

Los preview deployments te permiten ver cómo se verán los cambios en tu documentación antes de hacer merge a producción. Cada vista previa crea una URL para compartir que se actualiza automáticamente a medida que haces push de nuevos cambios.

<div id="creating-preview-deployments">
  ## Creación de deployments de vista previa
</div>

Los deployments de vista previa se crean automáticamente mediante pull requests o manualmente desde tu dashboard.

<div id="automatic-previews">
  ### Vistas previas automáticas
</div>

Cuando creas un pull request, el bot de Mintlify añade automáticamente un enlace para ver el deployment de vista previa en tu pull request. La vista previa se actualiza cada vez que haces push de nuevos commits a la branch.

<div id="manual-previews">
  ### Vistas previas manuales
</div>

Puedes crear manualmente una vista previa para cualquier branch.

1. Ve a tu [dashboard](https://dashboard.mintlify.com/).
2. Selecciona **Previews**.
3. Selecciona **Create preview**.
4. Ingresa el name de tu branch.
5. Selecciona **Create deployment**.

<div id="redeploying-a-preview">
  ## Volver a desplegar una vista previa
</div>

Vuelve a desplegar una vista previa para actualizar el contenido o reintentar después de un deployment fallido.

1. Selecciona la vista previa en tu [dashboard](https://dashboard.mintlify.com/).
2. Selecciona **Redeploy**.

<div id="sharing-preview-deployments">
  ## Compartir deployments de vista previa
</div>

Los deployments de vista previa pueden ser públicos o estar restringidos a usuarios autenticados.

**Acceso público**: Las URLs de vista previa son visibles públicamente de forma predeterminada. Comparte un enlace de vista previa con cualquier persona que necesite revisar tus cambios.

**Acceso restringido**: Habilita la Authentication para el deployment de vista previa para limitar el acceso únicamente a usuarios autenticados de Mintlify. Consulta [Authentication Setup](/es/deploy/authentication-setup) para obtener más información.
