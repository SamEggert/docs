Usamos tokens de acceso y webhooks para autenticar y sincronizar cambios entre GitLab y Mintlify.

- Mintlify usa tokens de acceso para obtener información de GitLab.
- GitLab usa webhooks para notificar a Mintlify cuando se realizan cambios, lo que habilita deployments de vista previa para las solicitudes de fusión.

<div id="set-up-the-connection">
  ## Configurar la conexión
</div>

<Note>
  **Se requiere clonación por HTTPS**: Tu proyecto de GitLab debe tener habilitada la clonación por HTTPS para que Mintlify pueda acceder a tu repositorio. Puedes verificarlo en GitLab yendo a **Settings** > **General** > **Visibility and access controls** de tu proyecto.
</Note>

<Steps>
  <Step title="Encuentra el ID de tu proyecto">
    En tu proyecto de GitLab, ve a **Settings** > **General** y localiza tu **Project ID**.
    <Frame>
      <img src="/images/gitlab/gitlab-project-id.png" alt="La página General Settings en el dashboard de GitLab. El Project ID está resaltado." />
    </Frame>
  </Step>
  <Step title="Genera un token de acceso">
    Ve a **Settings** > **Access Tokens** y selecciona **Add new token**.
    
    Configura el token con estos valores:
    - **Name**: Mintlify
    - **Role**: Maintainer (requerido para repos privados)
    - **Scopes**: `api` y `read_api`
    
    Haz clic en **Create project access token** y copia el token.

    <Note>
      Si los Project Access Tokens no están disponibles, puedes usar un Personal Access Token. Ten en cuenta que los Personal Access Tokens caducan y deben renovarse.
    </Note>

    <Frame>
      <img src="/images/gitlab/gitlab-project-access-token.png" alt="La página Access tokens en el dashboard de GitLab. Están resaltados los valores que configurar para Mintlify." />
    </Frame>

  </Step>
  <Step title="Configura la conexión">
    En el [Panel de control de Mintlify](https://dashboard.mintlify.com/settings/deployment/git-settings):
    1. Ingresa tu Project ID y el access token.
    2. Completa cualquier otra configuración requerida.
    3. Haz clic en **Save Changes**.
    <Frame>
      <img src="/images/gitlab/gitlab-config.png" alt="La página Git Settings en el Panel de control de Mintlify. Están resaltadas las configuraciones de GitLab." />
    </Frame>
  </Step>
</Steps>

<div id="create-the-webhook">
  ## Crear el webhook
</div>

Los webhooks nos permiten recibir eventos cuando se realizan cambios para poder
activar deployments automáticamente.

<Steps>
  <Step title="Ve a Settings > Webhooks y haz clic en 'Add new Webhook'">
    <Frame>
      <img src="/images/gitlab/gitlab-webhook.png" alt="Captura de pantalla de la página de Webhooks en el dashboard de GitLab." />
    </Frame>
  </Step>
  <Step title="Configura la URL y el webhook">
    En el campo "URL", introduce el punto de conexión `https://leaves.mintlify.com/gitlab-webhook` y asigna al webhook el name "Mintlify".

  </Step>
  <Step title="Pega el token">
    Pega el token del Webhook generado tras configurar la conexión.
    <Frame>
      <img src="/images/gitlab/gitlab-show-webtoken.png" alt="Captura de pantalla de la conexión de GitLab en el Panel de control de Mintlify. El botón Show Webtoken está resaltado." />
    </Frame>
  </Step>
  <Step title="Selecciona los eventos">
    Selecciona estos eventos para activar el webhook:
    - **Push events** (All branches)
    - **Merge requests events**
      
    Cuando termines, debería verse así:
    <Frame>
      <img src="/images/gitlab/gitlab-project-webtoken.png" alt="La página de Webhooks en el dashboard de GitLab. Los ajustes para configurar Mintlify están resaltados." />
    </Frame>
  </Step>
  <Step title="Prueba el Webhook">
    Después de crear el Webhook, haz clic en el menú desplegable "Test" y selecciona "Push events" para enviar una carga de ejemplo y comprobar que está configurado correctamente. Verás "Hook executed successfully: HTTP 200" si todo está bien.

    Esto te ayudará a verificar que todo funciona correctamente y que tu documentación se sincronizará adecuadamente con tu repositorio de GitLab.
    <Frame>
      <img src="/images/gitlab/gitlab-project-webtoken-test.png" alt="Captura de pantalla de la página de Webhooks de GitLab. El elemento de menú 'Push events' está resaltado en el menú 'Test'." />
    </Frame>

  </Step>
</Steps>
