---
title: "Páginas ocultas"
description: "Excluir páginas de tu navegación"
---

Las páginas ocultas se eliminan de la navegación de tu sitio, pero siguen siendo accesibles públicamente para cualquiera que conozca su URL.

Usa páginas ocultas para el contenido que quieres que sea accesible en tu sitio o que sirva como contexto para herramientas de IA, pero que no sea detectable a través de la navegación.

Para el contenido que requiera un control de acceso estricto, debes configurar la [Autenticación](/es/deploy/authentication-setup).

Si quieres ocultar páginas para grupos específicos de usuarios, usa la personalización para controlar la [visibilidad de la página](/es/authentication-personalization/overview#page-visibility).

<div id="hiding-a-page">
  ## Ocultar una página
</div>

Una página está oculta si no está incluida en la Navegación de tu `docs.json`. Para ocultar una página, elimínala de tu estructura de Navegación.

Las páginas ocultas utilizan la misma estructura de URL que las páginas regulares según su ruta de archivo. Por ejemplo, `guides/hidden-page.mdx` sería accesible en `docs.yoursite.com/guides/hidden-page`.

Consulta un [ejemplo de página oculta](/es/organize/hidden-page-example).

<Note>
  Algunos elementos de navegación, como las barras laterales, los menús desplegables y Tabs, pueden aparecer vacíos o alterar el diseño en las páginas ocultas.
</Note>

<div id="hiding-a-group-of-pages">
  ## Ocultar un grupo de páginas
</div>

Un grupo de páginas queda oculto si la propiedad `hidden` se establece en `true` en tu archivo `docs.json`:

```json highlight={4}
"groups": [
  {
    "group": "Primeros pasos",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  },
  {
    "group": "Guías",
    "pages": [
      "guides/hidden-page.mdx",
      "guides/hidden-groups.mdx"
    ]
  }
]
```

En este ejemplo, el grupo `Getting started` está oculto, pero el grupo `Guides` está visible.

<div id="hiding-a-tab">
  ### Ocultar una pestaña
</div>

También puedes ocultar una pestaña añadiendo la propiedad `hidden` a tu archivo `docs.json`:

```json highlight={4}
"tabs": [
  {
    "tab": "Inicio",
    "hidden": true,
    "pages": [
      "index",
      "quickstart"
    ]
  }
]
```

<div id="search-seo-and-ai-indexing">
  ## Búsqueda, SEO e indexación con IA
</div>

De forma predeterminada, las páginas ocultas se excluyen de la indexación para los motores de búsqueda, la búsqueda interna de tu documentación y como contexto para el Asistente de IA. Para incluir las páginas ocultas en los resultados de búsqueda y como contexto para el asistente, agrega la propiedad `seo` a tu `docs.json`:

```json
"seo": {
    "indexing": "all"
}
```

Para excluir una página específica, añade `noindex: true` a su frontmatter.
