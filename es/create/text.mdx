<div id="headers">
  ## Headers
</div>

Los Headers organizan tu content y crean anclajes de Navigation. Aparecen en la tabla de contenido y ayudan a los usuarios a recorrer tu documentación.

<div id="creating-headers">
  ### Creación de Headers
</div>

Usa los símbolos `#` para crear Headers de distintos niveles:

```mdx
## Header de sección principal
### Header de subsección
#### Header de sub-subsección
```

<Tip>
  Utiliza Headers descriptivos y ricos en palabras clave que indiquen claramente el content que sigue. Esto mejora tanto la Navigation del usuario como la optimización para motores de búsqueda.
</Tip>

<div id="disabling-anchor-links">
  ### Desactivar enlaces de anclaje
</div>

De forma predeterminada, los Header incluyen enlaces de anclaje en los que se puede hacer clic, lo que permite a los usuarios enlazar directamente a secciones específicas. Puedes desactivar estos enlaces de anclaje usando la prop `noAnchor` en Header de HTML o React.

<CodeGroup>
  ```mdx HTML header example
  <h2 noAnchor>
  Header sin enlace de anclaje
  </h2>
  ```

  ```mdx React header example
  <Heading level={2} noAnchor>
  Header sin enlace de anclaje
  </Heading>
  ```
</CodeGroup>

Cuando se usa `noAnchor`, el Header no mostrará la chip de anclaje y, al hacer clic en el texto del Header, no se copiará el enlace de anclaje al portapapeles.

<div id="text-formatting">
  ## Formato de texto
</div>

Compatibilizamos la mayoría del formato de Markdown para resaltar y dar estilo al texto.

<div id="basic-formatting">
  ### Formato básico
</div>

Aplica estos estilos de formato a tu texto:

| Estilo | Sintaxis | Ejemplo | Resultado |
|-------|--------|---------|--------|
| **Negrita** | `**texto**` | `**nota importante**` | **nota importante** |
| *Cursiva* | `_texto_` | `_énfasis_` | *énfasis* |
| ~~Tachado~~ | `~texto~` | `~función obsoleta~` | ~~función obsoleta~~ |

<div id="combining-formats">
  ### Combinación de formatos
</div>

Puedes combinar estilos de formato:

```mdx
**_negrita y cursiva_**
**~~negrita y tachado~~**
*~~cursiva y tachado~~**
```

***negrita y cursiva***<br />
**~~negrita y tachado~~**<br />
*~~cursiva y tachado~~*

<div id="superscript-and-subscript">
  ### Superíndice y subíndice
</div>

Para expresiones matemáticas o notas al pie, utiliza etiquetas HTML:

| Tipo | Sintaxis | Ejemplo | Resultado |
|------|--------|---------|--------|
| Superíndice | `<sup>text</sup>` | `example<sup>2</sup>` | example<sup>2</sup> |
| Subíndice | `<sub>text</sub>` | `example<sub>n</sub>` | example<sub>n</sub> |

<div id="links">
  ## Enlaces
</div>

Los enlaces ayudan a los usuarios a navegar entre páginas y acceder a recursos externos. Utiliza texto de enlace descriptivo para mejorar la accesibilidad y la experiencia del usuario.

<div id="internal-links">
  ### Enlaces internos
</div>

Enlaza a otras páginas de tu documentación usando rutas relativas a la raíz:

```mdx
[Inicio rápido](/quickstart)
[Steps](/components/steps)
```

[Inicio rápido](/es/quickstart)<br />
[Steps](/es/components/steps)

<Note>
  Evita los enlaces relativos como `[page](../page)`, ya que cargan más lento y no se pueden optimizar tan eficazmente como los enlaces relativos a la raíz.
</Note>

<div id="external-links">
  ### Enlaces externos
</div>

Para recursos externos, incluye la URL completa:

```mdx
[Guía de Markdown](https://www.markdownguide.org/)
```

[Guía de Markdown](https://www.markdownguide.org/)

<div id="broken-links">
  ### Enlaces rotos
</div>

Puedes verificar si hay enlaces rotos en tu documentación usando la [CLI](/es/installation):

```bash
mint broken-links
```

<div id="blockquotes">
  ## Citas en bloque
</div>

Las citas en bloque resaltan Información importante, citas o ejemplos dentro de tu content.

<div id="single-line-blockquotes">
  ### Citas en bloque de una sola línea
</div>

Agrega `>` antes del texto para crear una cita en bloque:

```mdx
> Esta es una cita que se destaca del contenido principal.
```

> Esta es una cita que se destaca del content principal.

<div id="multi-line-blockquotes">
  ### Citas en bloque de varias líneas
</div>

Para citas más largas o con varios párrafos:

```mdx
> Este es el primer párrafo de una cita en bloque de múltiples líneas.
>
> Este es el segundo párrafo, separado por una línea vacía con `>`.
```

> Este es el primer párrafo de una cita en bloque de varias líneas.
>
> Este es el segundo párrafo, separado por una línea vacía con `>`.

<Tip>
  Usa las citas en bloque con moderación para mantener su impacto visual y su significado. Considera usar [callouts](/es/components/callouts) para notas, advertencias y otra información.
</Tip>

<div id="mathematical-expressions">
  ## Expresiones matemáticas
</div>

Compatible con LaTeX para renderizar expresiones y ecuaciones matemáticas.

<div id="inline-math">
  ### Matemáticas en línea
</div>

Usa signos de dólar simples, `$`, para expresiones matemáticas en línea:

```mdx
El teorema de Pitágoras establece que $(a^2 + b^2 = c^2)$ en un triángulo rectángulo.
```

El teorema de Pitágoras afirma que $(a^2 + b^2 = c^2)$ en un triángulo rectángulo.

<div id="block-equations">
  ### Ecuaciones en bloque
</div>

Usa dos signos de dólar, `$$`, para ecuaciones independientes:

```mdx
$$
E = mc^2
$$
```

$$
E = mc^2
$$

<Info>
  La compatibilidad con LaTeX requiere una sintaxis matemática correcta. Consulta la [documentación de LaTeX](https://www.latex-project.org/help/documentation/) para obtener pautas completas sobre la sintaxis.
</Info>

<div id="line-breaks-and-spacing">
  ## Saltos de línea y espaciado
</div>

Controla los saltos de línea y el espaciado para mejorar la legibilidad del content.

<div id="paragraph-breaks">
  ### Saltos de párrafo
</div>

Separe los párrafos con líneas en blanco:

```mdx
Este es el primer párrafo.

Este es el segundo párrafo, separado por una línea en blanco.
```

Este es el primer párrafo.

Este es el segundo párrafo, separado por una línea en blanco.

<div id="manual-line-breaks">
  ### Saltos de línea manuales
</div>

Utiliza etiquetas HTML `<br />` para forzar saltos de línea dentro de los párrafos:

```mdx
Esta línea termina aquí.<br />
Esta línea comienza en una nueva línea.
```

Esta línea termina aquí.<br />
Esta línea comienza en una nueva línea.

<Tip>
  En la mayoría de los casos, los saltos de párrafo con líneas en blanco ofrecen mejor legibilidad que los saltos de línea manuales.
</Tip>

<div id="best-practices">
  ## Prácticas recomendadas
</div>

<div id="content-organization">
  ### Organización del content
</div>

* Usa Headers para crear una jerarquía clara del content
* Sigue la jerarquía adecuada de Headers (no pases de H2 a H4)
* Escribe texto de Header descriptivo y rico en palabras clave

<div id="text-formatting">
  ### Formato de texto
</div>

* Usa la negrita para el énfasis, no para párrafos completos
* Reserva la cursiva para términos, títulos o énfasis sutil
* Evita el exceso de formato que distraiga del content

<div id="links">
  ### Enlaces
</div>

* Escribe texto de enlace descriptivo en lugar de “haz clic aquí” o “leer más”
* Usa rutas relativas a la raíz para los enlaces internos
* Revisa los enlaces con regularidad para evitar referencias rotas
