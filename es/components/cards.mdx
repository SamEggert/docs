Usa Cards para crear contenedores visuales para content. Las Cards son contenedores flexibles que pueden incluir texto, icon, imágenes y enlaces.

<div id="basic-card">
  ## Card básica
</div>

<Card title="Card title" icon="text" href="/es/components/columns">
  Así es como se usa una Card con un icon y un enlace. Al hacer clic en esta Card
  irás a la página de Columns.
</Card>

```mdx Card example
<Card title="Título del Card" icon="text" href="/components/columns">
  Así es como usas un card con un icon y un enlace. Al hacer clic en este card
  te lleva a la página de Columns.
</Card>
```

<div id="card-variations">
  ## Variaciones de Card
</div>

Las Cards ofrecen varias opciones de diseño y estilo para adaptarse a diferentes necesidades de content.

<div id="horizontal-layout">
  ### Diseño horizontal
</div>

Agrega la propiedad `horizontal` para mostrar las Card en un diseño horizontal más compacto.

<Card title="Horizontal card" icon="text" horizontal>
  Este es un ejemplo de una Card horizontal.
</Card>

```mdx Horizontal card example
<Card title="Card horizontal" icon="text" horizontal>
  Este es un ejemplo de una card horizontal.
</Card>
```

<div id="image-cards">
  ### Cards con imagen
</div>

Agrega la propiedad `img` para mostrar una imagen en la parte superior de la Card.

<Card title="Image card" img="https://mintlify-assets.b-cdn.net/yosemite.jpg">
  Este es un ejemplo de una Card con imagen.
</Card>

```mdx Image card example
<Card title="Tarjeta de imagen" img="/images/card-with-image.png">
  Este es un ejemplo de una tarjeta con una imagen.
</Card>
```

<div id="link-cards-with-custom-ctas">
  ### Tarjetas de enlace con CTA personalizados
</div>

Puedes personalizar el texto del llamado a la acción y controlar si aparece una flecha. De forma predeterminada, las flechas solo se muestran en enlaces externos.

<Card title="Link card" icon="link" href="/es/components/columns" arrow="true" cta="Haz clic aquí">
  Este es un ejemplo de una Card con un icon y un enlace. Al hacer clic en esta Card, irás a la página de Columns.
</Card>

```mdx Link card example
<Card
  title="Tarjeta de enlace"
  icon="link"
  href="/components/columns"
  arrow="true"
  cta="Haz clic aquí"
>
  Este es un ejemplo de una tarjeta con un icon y un enlace. Al hacer clic en esta tarjeta te lleva a la página de Columns.
</Card>
```

<div id="grouping-cards">
  ## Agrupar cards
</div>

Usa el [componente Columns](/es/components/columns) para organizar varias cards lado a lado.

<Columns cols={2}>
  <Card title="First card" icon="panel-left-close">
    Esta es la primera card.
  </Card>

  <Card title="Second card" icon="panel-right-close">
    Esta es la segunda card.
  </Card>
</Columns>

```mdx Columns example
<Columns cols={2}>
  <Card title="Primera card" icon="panel-left-close">
    Esta es la primera card.
  </Card>
  <Card title="Segunda card" icon="panel-right-close">
    Esta es la segunda card.
  </Card>
</Columns>
```

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string" required>
  El title que se muestra en la Card
</ResponseField>

<IconsOptional />

<ResponseField name="color" type="string">
  Color del icon como código hexadecimal (por ejemplo, `#FF6B6B`).
</ResponseField>

<ResponseField name="href" type="string">
  URL a la que se navega cuando se hace clic en la Card.
</ResponseField>

<ResponseField name="horizontal" type="boolean">
  Mostrar la Card en un diseño horizontal compacto.
</ResponseField>

<ResponseField name="img" type="string">
  URL o ruta local de una imagen mostrada en la parte superior de la Card.
</ResponseField>

<ResponseField name="cta" type="string">
  Texto personalizado para el botón de acción.
</ResponseField>

<ResponseField name="arrow" type="boolean">
  Mostrar u ocultar el icon de flecha del enlace.
</ResponseField>
