---
title: 'Avisos'
description: 'Usa avisos para agregar contexto llamativo a tu contenido'
---

Los avisos se pueden configurar como Nota, Advertencia, Información, Sugerencia, Verificado, Peligro, o puedes crear tu propio aviso:

<Note>Esto agrega una nota en el contenido</Note>

```mdx
<Note>Esto añade una nota en el content</Note>
```

<Warning>Esto genera una Advertencia a la que debes estar atento</Warning>

```mdx
<Warning>Esto genera una advertencia que debe tenerse en cuenta</Warning>
```

<Info>Esto destaca información importante</Info>

```mdx
<Info>Esto resalta información importante</Info>
```

<Tip>Esto sugiere una Sugerencia útil</Tip>

```mdx
<Tip>Esto sugiere una sugerencia útil</Tip>
```

<Check>Esto nos devuelve un estado Verificado</Check>

```mdx
<Check>Esto nos da un estado verificado</Check>
```

<Danger>Este es un aviso de advertencia</Danger>

```mdx
<Danger>Esta es una alerta de peligro</Danger>
```

<Callout icon="key" color="#FFC107" iconType="regular"> Este es un aviso personalizado</Callout>

```mdx wrap
<Callout icon="key" color="#FFC107" iconType="regular">Esta es una llamada de atención personalizada</Callout>
```
