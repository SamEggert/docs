Los Accordion permiten a los usuarios expandir y contraer secciones de content. Usa los Accordion para la revelación progresiva y para organizar la Información.


<div id="single-accordion">
  ## Accordion individual
</div>

<Accordion title="Soy un Accordion.">
  Puedes poner cualquier content aquí, incluidos otros components, como código:

  ```java HelloWorld.java
   class HelloWorld {
       public static void main(String[] args) {
           System.out.println("Hello, World!");
       }
   }
  ```
</Accordion>

````mdx Accordion example
<Accordion title="Soy un Accordion.">
````

<div id="accordion-groups">
  ## Grupos de Accordion
</div>

Agrupa los accordions relacionados usando `<AccordionGroup>`. Esto crea una sección cohesiva de accordions que se pueden expandir o contraer individualmente.

<AccordionGroup>
  <Accordion title="Primeros pasos">
    Puedes colocar otros components dentro de Accordions.

    ```java HelloWorld.java
    class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, World!");
        }
    }
    ```
  </Accordion>

  <Accordion title="Funciones avanzadas" icon="bot">
    Agrega icon para que los accordions sean más distintivos visualmente y fáciles de escanear.
  </Accordion>

  <Accordion title="Solución de problemas">
    Mantén el content relacionado organizado en groups.
  </Accordion>
</AccordionGroup>

````mdx Accordion Group Example
<AccordionGroup>
  <Accordion title="Primeros pasos">

  </Accordion>

````


<div id="properties">
  ## Propiedades
</div>

<ResponseField name="title" type="string" required>
  Título en la vista previa del Accordion.
</ResponseField>

<ResponseField name="description" type="string">
  Detalle debajo del título en la vista previa del Accordion.
</ResponseField>

<ResponseField name="defaultOpen" type="boolean" default="false">
  Indica si el Accordion está abierto de forma predeterminada.
</ResponseField>
