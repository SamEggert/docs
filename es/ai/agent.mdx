<Info>
  El agente está disponible en los [planes Pro y Custom](https://mintlify.com/pricing?ref=agent) para cualquier persona con acceso a tu dashboard.
</Info>

El agente crea pull requests con cambios propuestos en tu documentación a partir de tus indicaciones. Cuando le envías una solicitud, hace referencia a tu documentación, repositorios conectados y mensajes de Slack para crear contenido que siga las mejores prácticas de redacción técnica y se ajuste al esquema de Mintlify. Accede al agente en tu espacio de trabajo de Slack o intégralo en aplicaciones personalizadas con la API.

Usa el agente para:

* Escribir contenido nuevo a partir de tus indicaciones, enlaces a pull requests o hilos de Slack
* Actualizar ejemplos de código obsoletos y referencias de API
* Buscar y actualizar contenido existente
* Responder preguntas sobre tu documentación y temas de redacción técnica

Para comenzar, añade el agente a tu espacio de trabajo de Slack y menciónalo con `@mintlify` en un canal.

<div id="add-the-agent-to-your-slack-workspace">
  ## Agrega el agente a tu espacio de trabajo de Slack
</div>

<Note>
  Si el propietario de tu espacio de trabajo de Slack requiere aprobación de administrador para instalar aplicaciones, pídele que apruebe la aplicación de Mintlify antes de conectarla.
</Note>

1. Ve a la página del [agente](https://dashboard.mintlify.com/products/agent) en tu dashboard.
2. Selecciona el botón **Connect**.
3. Sigue las indicaciones de Slack para añadir la aplicación `mintlify` a tu espacio de trabajo.
4. Sigue las indicaciones de Slack para vincular tu cuenta de Mintlify con tu espacio de trabajo de Slack.
5. Verifica que el agente funcione y responda cuando:
   * Le envíes un mensaje directo.
   * Lo menciones con `@mintlify` en un canal.

<div id="connect-repositories-as-context">
  ## Conectar repositorios como contexto
</div>

El agente solo puede acceder a los repositorios que conectes a través de la Aplicación de GitHub de Mintlify. Ajusta a qué repositorios puede acceder el agente en la [configuración de la Aplicación de GitHub](https://github.com/apps/mintlify/installations/new).

<div id="write-effective-prompts">
  ## Escribe prompts efectivos
</div>

Piensa en el agente como un asistente útil que necesita tu guía para completar tareas. Dale instrucciones claras y contexto. Las tareas más acotadas son más fáciles de completar, así que divide los proyectos complejos en pasos más pequeños.

Haz que tus prompts sean específicos y orientados a resultados. Prompts genéricos como `@mintlify Improve the onboarding page` aplican buenas prácticas generales, pero puede que no mejoren el contenido de la manera específica que tenías en mente.

Prueba prompts basados en los resultados que quieres que tus usuarios consigan o en los problemas que encuentran. Por ejemplo:

* `@mintlify A lot of users have trouble installing the CLI. Review the onboarding page and update the docs so that users can easily install the CLI`
* `@mintlify Developers keep getting 401 errors when following our authentication guide. Review the auth docs and add clearer examples showing how to properly format the API key`

Usa prompts más amplios para el mantenimiento general del contenido, como corregir errores tipográficos, actualizar redirecciones o renombrar una función en toda tu documentación. Por ejemplo:

* `@mintlify Find and fix all typos in the docs`
* `@mintlify change all unordered lists to use * instead of -`

<div id="agent-workflows">
  ## Flujos de trabajo del agente
</div>

El agente ayuda con diversas tareas de documentación. Estos flujos de trabajo muestran algunas formas de integrar el agente en tu proceso de documentación. Prueba un enfoque que se ajuste a la forma en que trabaja tu equipo y adáptalo a tus necesidades específicas.

<div id="iterate-on-a-prompt-in-a-slack-thread">
  ### Iterar un prompt en un hilo de Slack
</div>

Pide algo al agente y luego sigue mencionándolo con `@mintlify` en el mismo hilo para refinar e iterar el pull request que cree.

Por ejemplo: `@mintlify Nuestra página de inicio rápido necesita una nueva sección sobre cómo invitar a colaboradores`. Luego: `@mintlify La nueva sección debería llamarse "Inviting collaborators"`. Y así con cualquier otra iteración.

<div id="start-with-the-agent-finish-manually">
  ### Comienza con el agente, termina manualmente
</div>

Pídele al agente que inicie un proyecto, luego cambia a la branch que cree y termina la tarea en tu entorno local o en el editor web. El agente puede ayudarte a empezar y luego puedes continuar tú para completar la tarea.

Por ejemplo: `@mintlify Update the quickstart page to include information about inviting collaborators` y luego cambia a la branch para realizar cambios adicionales usando tu método preferido.

<div id="update-docs-when-merging-feature-changes">
  ### Actualiza la documentación al fusionar cambios de una funcionalidad
</div>

Cuando fusiones un pull request de una funcionalidad, comparte el enlace del PR con el agente para actualizar la documentación correspondiente.

Por ejemplo: `@mintlify Este PR agrega un nuevo método de Autenticación. Actualiza la documentación para incluir el nuevo flujo de auth: [PR link]`.

<div id="generate-release-notes-from-a-pull-request">
  ### Generar notas de versión a partir de un pull request
</div>

Pídele al agente un pull request específico para generar notas de versión o actualizaciones del changelog basadas en el historial de commits.

Por ejemplo: `@mintlify Genera notas de versión para este PR: [enlace al PR]`.

<div id="generate-code-examples">
  ### Generar ejemplos de código
</div>

Pídele al agente que genere ejemplos de código para funcionalidades en toda tu documentación o en páginas específicas.

Por ejemplo: `@mintlify Genera un ejemplo de código para que el método de Autenticación sea más fácil de entender`.

<div id="review-existing-content">
  ### Revisar el contenido existente
</div>

Pídele al agente que revise el contenido existente para verificar la precisión técnica, el estilo, la gramática u otros posibles problemas.

Por ejemplo: `@mintlify Review the API rate limiting section. We changed limits last month`.

<div id="respond-to-user-feedback">
  ### Responder a comentarios de usuarios
</div>

Proporciona al agente comentarios de tus usuarios para hacer actualizaciones puntuales en tu documentación.

Por ejemplo: `@mintlify Los usuarios se están confundiendo con el paso 3 de la guía de configuración. ¿Qué podría estar causando la confusión?`.

<div id="automate-with-the-api">
  ### Automatiza con la API
</div>

Integra el agente en tus herramientas de automatización existentes para actualizar la documentación automáticamente cuando haya cambios en el código, iniciar revisiones de contenido o sincronizar las actualizaciones de la documentación en múltiples repositorios.
