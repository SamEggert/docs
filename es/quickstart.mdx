Esta guía de inicio rápido te muestra cómo configurar e implementar tu sitio de documentación en cuestión de minutos.

Al completar esta guía, tendrás un sitio de documentación en producción, listo para personalizar y ampliar.

<Info>
  **Requisitos previos**: Antes de comenzar, [crea una cuenta](https://mintlify.com/start) y completa el proceso de incorporación.
</Info>

<div id="getting-started">
  ## Primeros pasos
</div>

Después de completar el proceso de incorporación, tu sitio de documentación se implementa automáticamente en una URL única con este formato:

```
https://<nombre-de-tu-proyecto>.mintlify.app
```

Encuentra tu URL en la página Overview de tu [dashboard](https://dashboard.mintlify.com/).

<Frame>
  <img src="/images/quickstart/mintlify-domain-light.png" alt="Mintlify Domain" className="block dark:hidden" />

  <img src="/images/quickstart/mintlify-domain-dark.png" alt="Mintlify Domain" className="hidden dark:block" />
</Frame>

La URL de tu sitio está disponible de inmediato. Usa esta URL para hacer pruebas y compartirla con tu equipo mientras configuras tu sitio de documentación.

<div id="install-the-github-app">
  ### Instala la GitHub App
</div>

Mintlify ofrece una GitHub App que automatiza la implementación cuando haces push de cambios a tu repositorio.

Instala la GitHub App siguiendo las instrucciones de la checklist de incorporación o desde tu dashboard.

1. Ve a **Settings** en tu dashboard de Mintlify.
2. Selecciona **GitHub App** en la barra lateral.
3. Selecciona **Install GitHub App**. Se abrirá una nueva pestaña con la página de instalación de la GitHub App.
4. Selecciona la organización o la cuenta de usuario donde quieres instalar la app.
5. Selecciona los repositorios que quieres conectar.

<Frame>
  <img src="/images/quickstart/github-app-installation-light.png" alt="GitHub App Installation" className="block dark:hidden" />

  <img src="/images/quickstart/github-app-installation-dark.png" alt="GitHub App Installation" className="hidden dark:block" />
</Frame>

<Info>
  Actualiza los permisos de la GitHub App si cambias tu documentación a otro repositorio.
</Info>

<div id="authorize-your-github-account">
  ### Autoriza tu cuenta de GitHub
</div>

1. Ve a **Settings** en tu dashboard de Mintlify.
2. Selecciona **My Profile** en la barra lateral.
3. Selecciona **Authorize GitHub account**. Se abrirá una nueva pestaña con la página de autorización de GitHub.

<Info>
  Es posible que un administrador de tu organización de GitHub deba autorizar tu cuenta, según la configuración de la organización.
</Info>

<div id="code-based-workflow">
  ## Flujo de trabajo basado en código
</div>

El flujo de trabajo basado en código se integra con tu entorno de desarrollo y repositorios de Git existentes. Este flujo de trabajo es ideal para equipos técnicos que quieren gestionar la documentación junto con el código.

<div id="install-the-cli">
  ### Instala la CLI
</div>

Para trabajar localmente con tu documentación, instala la interfaz de línea de comandos (CLI), llamada [mint](https://www.npmjs.com/package/mint), ejecutando este comando en tu terminal:

<CodeGroup>
  ```bash npm
  npm i -g mint
  ```

  ```bash pnpm
  pnpm add -g mint
  ```
</CodeGroup>

<Info>
  Necesitas tener Node.js instalado en tu equipo. Si tienes problemas durante la instalación, consulta la guía de solución de problemas.
</Info>

<div id="edit-the-documentation">
  ### Edita la documentación
</div>

Después de configurar tu entorno, puedes empezar a editar los archivos de documentación. Por ejemplo, actualiza el Título de la página de introducción:

1. Abre el repositorio que creaste durante la incorporación.
2. Abre `index.mdx` y ve al principio del archivo:

```mdx index.mdx
---
title: "Introducción"
description: "Esta es la introducción a la documentación"
---
```

3. Actualiza el campo `title` a `"Hello World"`.

```mdx index.mdx {2}
---
title: "Hola Mundo"
description: "Esta es la introducción a la documentación"
---
```

<div id="preview-the-changes">
  ### Vista previa de los cambios
</div>

Para ver una vista previa de los cambios localmente, ejecuta el siguiente comando:

```bash
mint dev
```

La vista previa estará disponible en `localhost:3000`.

<div id="push-the-changes">
  ### Publicar los cambios
</div>

Cuando estés listo para publicar tus cambios, súbelos a tu repositorio.

Mintlify detecta automáticamente los cambios, compila tu documentación y publica las actualizaciones en tu sitio. Supervisa el estado de la implementación en el historial de commits de tu repositorio de GitHub o en el [dashboard](https://dashboard.mintlify.com).

Una vez que la implementación se complete, tu actualización más reciente estará disponible en `<your-project-name>.mintlify.app`.

<Card title="Ir a agregar un domain personalizado" icon="arrow-down" href="#adding-a-custom-domain" horizontal>
  Opcionalmente, omite el flujo del editor web y ve a agregar un domain personalizado.
</Card>

<div id="web-editor-workflow">
  ## Flujo de trabajo del editor web
</div>

El flujo de trabajo del editor web ofrece una interfaz de lo que ves es lo que obtienes (WYSIWYG) para crear y editar documentación. Este flujo es ideal para quienes desean trabajar en su navegador sin herramientas adicionales de desarrollo local.

<div id="access-the-web-editor">
  ### Accede al editor web
</div>

1. Inicia sesión en tu [dashboard](https://dashboard.mintlify.com).
2. Selecciona **Editor** en la barra lateral izquierda.

<Info>
  Si no tienes instalada la GitHub App, se te pedirá que la instales al abrir el editor web.
</Info>

<Frame>
  <img alt="El editor web de Mintlify en modo editor visual" src="/images/quickstart/web-editor-light.png" className="block dark:hidden" />

  <img alt="El editor web de Mintlify en modo editor visual" src="/images/quickstart/web-editor-dark.png" className="hidden dark:block" />
</Frame>

<div id="edit-the-documentation">
  ### Edita la documentación
</div>

En el editor web, puedes navegar por tus archivos de documentación desde la barra lateral. Actualicemos la página de introducción:

Busca y selecciona `index.mdx` en el explorador de archivos.

Luego, en el editor, actualiza el campo Título a &quot;Hello World&quot;.

<Frame>
  <img alt="Edición en el editor web" src="/images/quickstart/web-editor-editing-light.png" className="block dark:hidden" />

  <img alt="Edición en el editor web" src="/images/quickstart/web-editor-editing-dark.png" className="hidden dark:block" />
</Frame>

<Tip>
  El editor ofrece un conjunto completo de herramientas de formato y components. Escribe <kbd>/</kbd> en el editor para abrir el menú de comandos y acceder a estas herramientas.
</Tip>

<div id="publish-your-changes">
  ### Publica tus cambios
</div>

Cuando estés satisfecho con tus cambios, selecciona el botón **Publish** en la esquina superior derecha. Tus cambios se publican de inmediato en tu sitio de documentación.

<Tip>
  Usa branches para previsualizar y revisar cambios mediante pull requests antes de publicar en tu sitio en producción.
</Tip>

Para más detalles sobre cómo usar el editor web, incluido el uso de branches y pull requests para colaborar y previsualizar cambios, consulta nuestra [documentación del editor web](/es/editor/getting-started).

<div id="adding-a-custom-domain">
  ## Agregar un domain personalizado
</div>

Si bien tu Subdomain `<your-project-name>.mintlify.app` funciona bien para pruebas y desarrollo, la mayoría de los equipos prefieren usar un domain personalizado para la documentación de producción.

Para agregar un domain personalizado, ve a la página [Domain Setup](https://dashboard.mintlify.com/settings/deployment/custom-domain) en tu dashboard.

<Frame>
  <img src="/images/quickstart/custom-domain-light.png" alt="Custom Domain" className="block dark:hidden" />

  <img src="/images/quickstart/custom-domain-dark.png" alt="Custom Domain" className="hidden dark:block" />
</Frame>

Ingresa tu domain (por ejemplo, `docs.yourcompany.com`) y sigue las instrucciones proporcionadas para configurar los registros DNS (Domain Name System) con tu proveedor de domain.

<Table>
  | Record Type | Name | Value | TTL |
  |-------------|------|-------|-----|
  | CNAME | docs (o subdomain) | cname.mintlify.app | 3600 |
</Table>

<Info>
  Los cambios de DNS (Domain Name System) pueden tardar hasta 48 horas en propagarse, aunque a menudo se completan mucho antes.
</Info>

<div id="troubleshooting">
  ## Solución de problemas
</div>

Si encuentras problemas durante el proceso de configuración, revisa estas soluciones comunes:

<AccordionGroup>
  <Accordion title="La vista previa local no funciona">
    Asegúrate de tener Node.js v19+ instalado y de ejecutar el comando `mint dev` desde el directorio que contiene tu archivo `docs.json`.
  </Accordion>

  <Accordion title="Los cambios no se reflejan en el sitio en producción">
    La implementación puede tardar varios minutos. Verifica tus GitHub Actions (para flujos de trabajo basados en código) o los registros de implementación en el dashboard de Mintlify para asegurarte de que no haya errores de compilación.
  </Accordion>

  <Accordion title="El dominio personalizado no se conecta">
    Verifica que tus registros DNS estén configurados correctamente y permite suficiente tiempo para la propagación de DNS (hasta 48 horas). Puedes usar herramientas como [DNSChecker](https://dnschecker.org) para verificar tu registro CNAME.
  </Accordion>
</AccordionGroup>
